## 1. 为什么需要滤波？

相机每帧测一次敌人位置，但每次测量都有误差（±几 cm 甚至更糟）。直接用测量值会怎样？

- 云台跟着噪声抖，永远稳不下来；
- 目标被遮挡一瞬间（temp_lost），测量直接消失；
- 你要打的是**弹丸到达时刻**的位置——需要外推。

**滤波 = 融合"模型的预测"和"带噪的测量"，得到比两者都准的估计。**

## 2. 用一个温度计理解卡尔曼滤波（5 分钟版）

估计当前温度，手上有两个信息：

```
预测值  x̂⁻ = 25.0°   （基于昨天的趋势外推）
预测的"自信度" P⁻ = 2.0   （方差：越大越不自信）
测量值  z  = 26.0°
测量的噪声  R = 0.5        （温度计标定已知）
```

卡尔曼增益 = "按各自的不确定度分配权重"：

```
K = P⁻ / (P⁻ + R) = 2.0/2.5 = 0.8     → 更信测量（它更准）
x̂  = x̂⁻ + K·(z − x̂⁻) = 25 + 0.8·1 = 25.8°
P  = (1−K)·P⁻ = 0.4                    → 融合后更自信了
```

**全部卡尔曼滤波的直觉都在这**：K 是权衡旋钮，P 大信测量、R 大信模型。每一步更新后不确定度下降，下一帧预测时 P 又按过程噪声 Q 涨回去——如此滚动。

## 3. 多维卡尔曼滤波五公式（背下来）

状态 x（向量），协方差 P（矩阵：对角线=各维方差，非对角=相关）：

```
预测:   x̂⁻ = F·x̂          P⁻ = F·P·Fᵀ + Q
更新:   K  = P⁻·Hᵀ·(H·P⁻·Hᵀ + R)⁻¹
        x̂  = x̂⁻ + K·(z − H·x̂⁻)
        P  = (I − K·H)·P⁻
```

- **F**：状态转移矩阵（上一状态 → 预测下一状态）。匀速模型的 F 是 `[1 dt; 0 1]` 块的堆叠；
- **Q**：过程噪声（"我猜目标会机动，模型不完全准"）；
- **H**：观测矩阵（状态里哪些量能被直接看到）；
- **R**：测量噪声；
- **残差** `z − H·x̂⁻`：测量和预测的差。

## 4. EKF：唯一区别是 h(x) 非线性

问题：本项目的观测不是"x 在哪"，而是 **(yaw, pitch, distance, 装甲板朝向)**——这是状态的非线性函数（atan2、开方）。非线性函数没法直接用矩阵 H。

**EKF 的做法**：在当前点把 h(x) 用泰勒展开取一阶（线性化），H 用**解析雅可比**代替：

```
H = ∂h/∂x   （在当前估计点求值）
```

项目代码（target.cpp:187-223, 280-317）：

```cpp
// 观测函数（非线性）
xyz = h_armor_xyz(x, id);            // 由旋转中心+半径算出装甲板位置
ypd  = xyz2ypd(xyz);
z_pred = {ypd[0], ypd[1], ypd[2], limit_rad(x[6] + id·2π/N)};

// 雅可比（两段链式相乘）
H = H_armor_ypda · H_armor_xyza;     // 球坐标雅可比 × 装甲板几何雅可比
```

## 5. 项目 11 维状态逐项讲解（对照 target.cpp）

```
x = [ x, vx,  y, vy,  z, vz,  a,  w,  r,  l,  h ]
     └─旋转中心位置+速度─┘  └相位,转速┘ └几何参数┘
```

**为什么这么设计**（这是整车模型的精髓）：

- 不跟踪单块装甲板，而跟踪**旋转中心 + 转速**——小陀螺时装甲板在切换，中心不变；
- `a`（相位角）+ `w`（角速度）让你预测"下一秒哪块板转过来"；
- `r, l, h` 是装甲板几何参数，**当作状态在线估计**（随机游走），而不是标定值——普通 4 板车两组对边半径不同（r+l），用 l、h 在线学出来。

### 5.1 预测（predict，target.cpp:75-136）

匀速 + 匀角速度模型：位置/速度对与 (a,w) 对都用 `[1 dt; 0 1]` 块；r,l,h 不变（F=1）。

过程噪声 Q（Piecewise White Noise）：

```
普通车: v1=100 (加速度方差), v2=400 (角加速度方差)
前哨站: v1=10, v2=0.1   →  更信模型（前哨转速固定）
```

### 5.2 更新（update，:138-223）

**装甲板匹配**（观测到哪块板了？）：模型预测出全部 N 块板，取最近 3 块，按"朝向差 + 方位角差"最小者配对。

**观测向量与噪声**：

```cpp
z = { yaw, pitch, distance, armor_yaw };
R = diag( 4e-3, 4e-3,
          log(|Δ朝向|+1)+1,        // ★ 侧对时距离噪声放大（PnP深度不可信）
          log(d+1)/200 + 0.09 );   // ★ 距离越远朝向观测越不准
```

**自适应 R 是本项目的亮点**：噪声不是常数，而是随观测质量变化——这是"把物理直觉编码进滤波器"。

### 5.3 发散/收敛保护

- `diverged()`：估计出的半径超出 (0.05, 0.5) m → 模型崩了，tracker 强制重置；
- `convergened()`：更新次数够多 → 允许换目标等高级操作；
- NIS 滑窗失败率 ≥40% → "模型与观测长期不匹配" → 放弃目标。

## 6. Joseph 形式（为什么代码的 P 更新长一点）

普通形式 `P = (I−KH)P⁻` 在浮点误差累积下可能失去对称正定性（P 变坏 → 滤波器发疯）。Joseph 形式（ekf.cpp:52-54）：

```cpp
P = (I−K·H)·P·(I−K·H)ᵀ + K·R·Kᵀ;
```

数学上等价但**数值上永远稳定**。以后写 EKF 无脑用 Joseph。

## 7. 卡方检验（NIS/NEES）：滤波器的"自检"

每次更新算一个统计量：

```
NIS = 残差ᵀ · S⁻¹ · 残差    （S = H·P·Hᵀ + R，新息协方差）
```

若模型匹配，NIS 应服从卡方分布。项目用滑窗 100 次、失败率阈值 40% 来判断"模型还靠谱吗"。

⚠️ 项目注释里 threshold=0.711 实为 χ²(4) 的 **5% 下分位**（95% 上分位是 9.488）——单独看这个阈值几乎每次都"失败"，是配合 40% 失败率成对使用的激进工程参数。**学到的教训：统计阈值必须成对理解，不能抄一半。**

## 8. 前哨站的三个特化（阅读 target.cpp 时的地图）

1. 装甲板数 N=3、半径 0.2765m **视为已知常量**（P0 的 r/l/h 方差≈0）；
2. 过程噪声 v1/v2 = 10/0.1（转速固定，更信模型）；
3. 收敛后 |w|>2 时直接钳到 ±2.51 rad/s（官方固定转速 2.5s/圈 = 2π/2.5）。

**启示**：对已知约束的强先验比万能模型更好用。

## 9. 角度卷绕（新手必踩的坑，重复一次）

任何涉及角度的 EKF 必须**三处**处理 ±π 回绕：

```cpp
x_add(a, b)  → limit_rad(a + b)        // 状态加法
f(x)         → limit_rad(x[6])          // 预测后
z_subtract(z, h(x)) → limit_rad(z − h)  // 残差
```

漏掉任意一处：目标在 ±π 附近时残差突然变成 ~2π，滤波器输出巨大跳变，云台疯转。
