学习笔记 00 —— 学习路线图（写给只有 C++ 基础的你）

Published: 2026-11-08  •  Reading Time: 4 mins

目标：从”大二、只学过 C++ 基础”到”能看懂 sp_vision_25 自瞄项目、能改其中的模块”。 本文件夹 8 篇笔记按依赖顺序排列，每篇结尾有过关自测——答得上来就进下一篇。

一、这个项目到底需要哪些知识？

对着项目源码反推，需要 6 块知识：

                    ┌────────────────────────────┐
                    │      自瞄 = 感知 + 估计 + 决策 + 执行      │
                    └────────────────────────────┘
   感知 ←── C++进阶 + OpenCV + 神经网络/YOLO
   估计 ←── 线性代数/坐标变换 + 卡尔曼滤波
   决策 ←── 控制基础(PID/弹道/MPC) + 状态机
   执行 ←── 通信(串口/CAN) + 多线程 + Linux/CMake

好消息：没有任何一块需要天赋，全是可以按周学完的。坏消息：每一块都要动手写代码才能真会。

二、学习顺序（严格按这个来，不要跳）

阶段 内容 笔记 建议时长 动手任务
0 C++ 进阶 + Linux 入门 01 / 07 2 周 用多线程写一个生产者-消费者小程序
1 线性代数 + Eigen + OpenCV 02 / 05 3 周 做一个灯条检测 demo（见下）
2 概率与卡尔曼滤波 03 2 周 手写一维卡尔曼滤波（50 行）
3 控制基础 + 弹道 04 1 周 手写 PID 控制一个 simulated 一阶系统
4 神经网络与 YOLO 06 2 周 用 OpenCV dnn 跑一个现成 YOLO onnx
5 通读本项目的拆解文档 + 源码 ../视觉/ ../电控/ 2 周 跑通 tests/ 里的 3 个测试

总计约 3 个月（课余）。阶段 1 的灯条检测 demo 是最重要的一关——做完它你就理解了传统视觉 70% 的套路。

灯条检测 demo 具体要求

拿一张 RM 装甲板照片（官网/开源仓库都有），用 OpenCV 完成：

  1. cvtColor 灰度化 → threshold 二值化 → findContours 找轮廓
  2. minAreaRect 拟合灯条，打印每根灯条的长宽比和角度
  3. 筛掉 ratio < 3 的”假灯条”，把剩下的画框显示出来
  4. 加分：把两根灯条配对成装甲板，画在图上

做完这个再对照 视觉/02-传统检测器，你会发现项目代码就是把你的 demo 参数化、加固了十倍。

三、每个阶段的过关自测

阶段 0（C++/Linux）自测

  • unique_ptr 和裸指针的区别？为什么项目用 unique_ptr<YOLOBase>？
  • std::mutex + condition_variable 解决什么问题？
  • 两个线程同时写一个 int 会发生什么？怎么解决？
  • Linux 下怎么给 /dev/ttyACM0 加权限？

阶段 1（数学/OpenCV）自测

  • 旋转矩阵为什么是正交的？R·Rᵀ = ?
  • 相机内参 fx, fy, cx, cy 各是什么意思？
  • solvePnP 的输入输出是什么？为什么装甲板 4 个点就够？
  • minAreaRect 返回什么？怎么从它得到灯条端点？

阶段 2（滤波）自测

  • 为什么要滤波而不是直接用测量值？
  • Q 调大意味着更信测量还是更信模型？R 呢？
  • EKF 和 KF 的唯一区别是什么？
  • 为什么角度状态要 limit_rad 到 ±π？

阶段 3（控制）自测

  • PID 三个项各自的物理意义？D 项为什么用”微分先行”？
  • 打移动目标为什么不能直接瞄当前位置？（飞行时间提前量）
  • MPC 和 PID 的本质区别是什么？

阶段 4（YOLO）自测

  • softmax 输出的含义？置信度 0.7 阈值过滤的是什么？
  • NMS 在解决什么问题？
  • pt → onnx → IR(.xml/.bin) 转换链是怎么回事？

四、推荐资源（少而精）

主题 资源 说明
C++ 进阶 《Effective Modern C++》选读 + cppreference.com 查语法用 cppreference，别背书
线性代数 3Blue1Brown《线性代数的本质》（B 站，免费） 先看这个建立直觉，再看任何教材都不怕
卡尔曼滤波 rlabbe《Kalman and Bayesian Filters in Python》（GitHub 免费开源，有中文翻译） 项目 EKF 代码注释里引用的就是它
OpenCV OpenCV 官方 C++ Tutorials + 《Learning OpenCV》 边看边跑
深度学习 李沐《动手学深度学习》（B 站免费） 看前 6 章够用
YOLO ultralytics 官方文档 只需要懂训练和导出
ROS（后期） 古月居 ROS2 入门 项目里 ROS 是可选项，最后再看

五、心态建议

  1. 先跑通，再读懂，最后改对。每接触一个新模块，先编译运行对应的 tests/*_test，看现象，再回头读代码；
  2. 别怕数学。项目里的数学全部是本科二年级范围内：线代、概率、一元二次方程。推导看不懂就先记住结论和直觉，用起来再回头补；
  3. 每篇笔记里的”结合项目”小节是钥匙——把抽象知识和具体代码挂钩，比刷教材快得多；
  4. 卡住超过半天就去找人问或者把问题写下来继续往下走，不要在单个知识点上死磕。
